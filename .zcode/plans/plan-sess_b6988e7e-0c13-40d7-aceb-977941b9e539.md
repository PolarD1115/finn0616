## Step 7：JS 实现（替换第918-967行）

### 防护函数
- `round(n)` = `Math.round(Number(n)||0)`
- `fmtNullTime(iso)` = `iso ? fmtCN8(iso) : "还没有过"`
- `fmtAction(a)` — income→收入/expense→支出/transfer→转账/adjust→调整
- `fmtStatus(s)` — idle→闲逛/sleeping→睡觉 等

### Supabase 初始化 `getSb()`
localStorage 读 URL+Key → **不以 `https://` 开头→toast报错返回null** → `createClient(url,key)`

### loadStatus(force)
显示配置区 → `getSb()` → 并行 `loadWallet/loadPets/loadHouse`

### loadWallet(sb)
- `Promise.all` 查 `wallet.select("*").limit(1)` + `wallet_log.select("*").order("created_at",{ascending:false}).limit(10)`
- **空数据兜底**：`const wallet=(w&&w[0])||{}`；`balance=round(wallet.balance)||0`
- **环形图**：`totalEarned=round(wallet.total_earned)||0`；`totalSpent=Math.max(0, round(totalEarned + 100 - balance))`；两段（绿=累计收入/珊瑚=累计支出），中心显示余额
- statCard ×4：余额/本周收入/累计收入/累计支出（近似）
- 流水列表：卡片式，action中文化，金额±前缀

### renderDonut(id, balance, totalEarned, totalSpent)
SVG circle，stroke-dasharray 分两段，中心余额大字+"当前余额"，下方图例

### loadPets(sb)
- 并行查 `pets.select("*")` + `pet_inventory.select("*").gt("quantity",0)`
- **空数据兜底**：`const pet=(pets&&pets[0])||{}`；无宠物→条形图区显示"还没有宠物"
- 横向条形图：复用 `dimRow(name,num,pct,cls)`，5条（饥饿orange/快乐blue/清洁teal/精力orange/健康blue），值经round()
- 详情表：全字段，last_fed等经fmtNullTime()
- 库存：grid卡片，quantity经round()，空→"背包空空如也"

### loadHouse(sb)
- 并行查 `house_rooms.select("*").order("sort_order").limit(5)` + `house_diary.select("*").order("created_at",{ascending:false})` + `house_objects.select("*").eq("is_hidden",false)`
- **空数据兜底**：各数组为空→"暂无房间"/"暂无物品"/"还没有日记"
- 房间卡：emoji+name+description；物品卡：emoji+name；日记卡：时间+entry_type+mood标签+content

### toggleStatusAuto()
`_pollers.status` 键（被 showPage clearPollers 自动清理）

## 防护点对照

| 防护点 | 实现 |
|---|---|
| 数值取整 | `round()` 覆盖所有numeric |
| null时间 | `fmtNullTime()`→"还没有过" |
| URL须https:// | `getSb()`中`startsWith("https://")`校验 |
| wallet_log倒序10条 | `.order("created_at",{ascending:false}).limit(10)` |
| pet_inventory过滤0 | `.gt("quantity",0)` |
| house_diary倒序 | `.order("created_at",{ascending:false})` |
| **环形图支出公式** | `Math.max(0, round(total_earned + 100 - balance))` |
| **空表兜底** | `data?.[0]\|\|{}` + `round(x)\|\|0` + 空数组→"暂无…" |
| **轮询清理** | `_pollers.status` 键，showPage `clearPollers()` 自动清 |
