聊天记录写入

关闭后，网页/Telegram/QQ 三个渠道都不再把本轮对话写入 memories 流水与 Pinecone。不影响手动保存记忆、已有记忆读取、必要的系统状态记录（Core_Cognition/日记/总结）。

向量记忆检索注入

关闭后，网页/Telegram/QQ 三个渠道构建 prompt 时都跳过 Pinecone 检索。不影响普通 user_facts 画像注入、Core_Cognition 注入、Pinecone 数据本身。

设备数据注入

控制前台聊天（网页/Telegram/QQ）是否自动把手机最新设备状态（位置、前台应用、健康、睡眠、通知等）注入对话上下文。关闭后前台对话不再自动附带设备快照，但 AI 仍可通过「设备状态查询」工具主动查询。不影响后台自主活动（主动问候/自由活动仍按 DEVICE_CONTEXT_ENABLED 环境变量注入）。

Agent 赚钱系统

开启：允许 Agent 通过自主任务赚钱（wallet_earn）。关闭：禁止 Agent 自主入账。不影响钱包余额、消费、猫用品购买、零花钱和打赏。

安全重启 部分进程级配置需重启生效

所有开关均为运行时读取（5s 热生效），无需重启。仅当修改环境变量（.env）或 NapCat 连接参数时才需要重启进程。
